# 📈 Stock Market Prediction System

A complete end-to-end deep learning project for forecasting **NIFTY** and **BANKNIFTY** stock prices using **LSTM** (Long Short-Term Memory) neural networks, enriched with technical indicators and real-time data visualization.

---

## 🚀 Key Features

- 🔮 Predict future prices of NIFTY/BANKNIFTY using LSTM
- 📉 Technical indicators: SMA, RSI, MACD, Bollinger Bands
- 📊 Visualize historical trends and future predictions
- 🧠 Scalable deep learning model trained on real market data
- 🌐 Flask-based API for serving predictions
- 📈 Optional TradingView integration for live charts
